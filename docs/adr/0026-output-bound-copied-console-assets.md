# 0026: Retain output-bound copied Console assets

Date: 2026-10-27

Status: Accepted

## Context

The native Console includes copied icon/font/flag assets outside the Angular
package notice text. The text-font inventory deliberately records 32 icon-font
outputs separately. Package labels and a repository's root license cannot
substitute for the actual selected assets and their original notices.

## Decision

Add an explicit copied-assets companion to the existing icon command. Close the
1,561-file Line Awesome subtree, four Material Icons formats and 271 flags against
frozen original identities, all 3,672 generated copies and the actual compiler's
1,836 selected embeds. Preserve complete original terms, copyrights, available
TTF attribution records, and both original/modified CSS identities.

Inspect the real connected packages through confined single-hop pnpm aliases,
with exact metadata and lock bindings. The frontend has already consumed these
packages when the pre-compilation snapshot runs. Original archive capture occurs
later in the existing complete source adapter; retain that independent integrity
and native offline replay boundary rather than introducing another tar parser.

Bind unchanged pre/post observations to the existing font collector's canonical
recipe, preparation, toolchain, binary and final receipt checks. Capture only
pending builds, retain both text and inventory, and require read-only completed
verification before image packaging. Include their identities in the retained
offline replay receipt and preserve all seven new literal source records.

## Consequences

The prepared upstream tree and public website behaviour do not change. The
explicit image package grows from 15 to 17 payload files; source/build records
grow from 18 to 25. Existing text-font completeness, source retention, image
restrictions and native service/browser controls remain required.

This is a bounded attribution delivery under #308, implemented by #380. Other
graphics/marks and complete distribution/source-offer/publication obligations
remain separate. No image admission, full licensing clearance, reproducibility
or production portal activation is inferred from this inventory.
